## Generic model (proposal)

- **Game** → **Category** (e.g. "Time Trial 150cc", "High round", "EE speedrun") with a field
  template (time / round / number / text / choice / track-map / players) and a ranking rule
  (lower-is-better time, higher-is-better round, time-to-round…).
- **Record** = category + values + participants (accounts or guest names) + date + proofs + notes.
- MKW and CoD Zombies ship as pre-loaded templates; any user can add games/categories from the UI.
